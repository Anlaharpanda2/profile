# Anla Harpanda - Portfolio 🚀

Personal portfolio website built with modern technologies to showcase my projects, skills, and experience as a Full Stack Web Developer & UI/UX Designer.

## 🌟 Features
- **Modern & Responsive Design**: Built with Next.js 15 and TailwindCSS for a premium look and feel.
- **Dynamic Projects Showcase**: Automated filtering and detailed case studies for each project.
- **AI Chat Assistant**: Integrated Google Gemini AI to answer questions about my professional background.
- **Interactive Resume**: Online resume with real-time project metrics and key learnings.
- **SEO Optimized**: Complete metadata, JSON-LD structured data, sitemap, and robots.txt.
- **Dark/Light Mode**: Full support for system preferences and manual toggle.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router with Static Export)
- **Deployment**: Cloudflare Pages
- **Styling**: TailwindCSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Serverless Functions**: Cloudflare Pages Functions
- **Analytics**: Google Tag Manager

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS)
- pnpm (Recommended)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/itsanla/Personal-Landing-Page.git
   ```
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Set up environment variables:
   Create a `.env.local` file in the root directory and add your Google API Key for the chat feature:
   ```env
   GOOGLE_API_KEY=your_gemini_api_key_here
   ```

### Development
Run the development server:
```bash
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build
To create a production build:
```bash
pnpm build
```

### Preview
To preview the static build locally:
```bash
pnpm preview
```

### Deploy to Cloudflare Pages
See [CLOUDFLARE_DEPLOYMENT.md](CLOUDFLARE_DEPLOYMENT.md) for detailed deployment instructions.

## 📂 Project Structure
- `app/`: Next.js App Router components and routes.
- `functions/`: Cloudflare Pages Functions (serverless API endpoints).
- `app/components/`: Reusable UI components and sections.
- `data/`: Core project data and static information.
- `public/`: Assets like images, logos, and PDFs.
- `out/`: Static build output (generated by `pnpm build`).
